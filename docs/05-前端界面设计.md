# 05 前端界面设计（Web Dashboard）

## 1. 设计目标与约束

- **简单**：原生 HTML + CSS + JavaScript，无框架、无构建步骤、无 CDN 依赖，刷新即用。
- **只读展示 + 轻量控制**：监控为主，辅以演示控制（故障注入、状态切换、重置、调参）。
- **数据来源**：仅通过 fetch 调用服务层 HTTP API（契约见 04 文档 §4）。
- **刷新策略**：主指标 2 秒轮询；状态迁移时间线 2 秒轮询；柱状图随详情接口刷新。

## 3. 功能模块

### 3.1 全局指标栏

- 数据：`GET /api/metrics`（`GlobalMetrics`）。
- 展示：总请求、成功、失败、拒绝（熔断+并发）、整体错误率（进度条着色）。
- 轮询：2 秒。

### 3.2 熔断器列表

- 数据：`GET /api/breakers`（摘要数组）。
- 每条渲染：资源名、状态徽章（closed=绿 / open=红 / half_open=黄，带圆点）、错误率、请求量、拒绝量。
- 交互：点击选中 → 加载详情；选中项高亮；右上角支持输入资源名"添加"（POST 走 `GetOrCreate` 语义，前端仅发新建请求）、"删除"。
- 状态徽章随轮询刷新，状态变化时闪烁提示（CSS class 切换）。

### 3.3 详情面板

- 数据：`GET /api/breakers/{name}`（`BreakerDetail`）。
- 内容：
  1. **头部**：资源名、状态徽章、最近熔断时间、冷却剩余（前端按 OpenedAt + SleepWindow 本地推算）。
  2. **指标卡**：请求总数 / 成功 / 失败 / 超时 / 熔断拒绝 / 并发拒绝 / 探测成功 / 探测失败 / 当前并发 / P95 耗时。
  3. **滑动窗口柱状图**：从 `window.buckets` 渲染最近 10 桶，每桶一列：
     - 绿段 = succeeded，红段 = failed，橙段 = timeouts，灰段 = rejected（按比例堆叠）。
     - 无第三方图表库：`div` 绝对定位 + 百分比高度实现。
  4. **状态迁移时间线**：`GET /api/events?resource={name}` 过滤渲染，每条：时间、事件类型、from→to、原因。
  5. **配置表**：可编辑输入框（阈值、窗口、冷却、并发、超时等），点击"保存"调 `PUT .../config`；"重置"调 `POST .../reset`；"切换状态"下拉框调 `POST .../state`。
  6. **手动探测**按钮：调 `POST .../probe`。

### 3.4 演示控制台

- 数据：`POST /api/demo/simulate` / `POST /api/demo/stop` / `GET /api/demo/status`。
- 控件：资源下拉（取列表）、失败率滑杆（0-100%）、延迟输入（ms）、持续秒数；按钮「注入故障」「停止注入」。
- 状态提示：当前注入中的资源与其参数（每秒本地倒数）。

## 4. 交互流程

### 4.1 常规轮询

```
onLoad → init()
  ├─ loadBreakers()      // 渲染列表，默认选中第一项
  ├─ loadGlobal()        // 全局指标栏
  └─ setInterval(2s): loadBreakers + loadGlobal + loadDetail(选中项)

选中变化 → loadDetail(name)
  ├─ 详情面板渲染（指标/柱状图/时间线/配置）
  └─ 若 window.buckets 长度变化 → 重建柱状图

轮询中若列表出现新状态徽章 → 应用闪烁动画（3 次渐变）
```

### 4.2 演示流程（观察三态全流程）

```
1. 在演示控制台选择 payOrder，失败率 80%，时长 15s，点「注入故障」
2. 前端业务请求持续打到 payOrder → 错误率爬升 → 列表徽章变红（closed→open）
3. 冷却 5s 后徽章变黄（open→half_open），柱状图出现少量探测成功绿柱
4. 注入停止后，连续探测成功 → 徽章变绿（half_open→closed）
5. 时间线完整记录上述迁移
```

## 5. 文件划分与职责

| 文件 | 职责 | 预估行数 |
| --- | --- | --- |
| `web/index.html` | 页面骨架：顶栏、全局栏、左右面板、演示控制台、模态容器 | ~180 |
| `web/style.css` | 布局（flex/grid）、徽章配色、柱状图样式、闪烁动画、响应式 | ~220 |
| `web/app.js` | 状态管理（选中项、注入状态）、fetch 封装、渲染函数、轮询调度、柱状图绘制、表单操作 | ~380 |

## 6. 前端数据结构映射

| 前端对象 | 来源接口 | 关键字段 |
| --- | --- | --- |
| `BreakerSummary` | GET /api/breakers | resource, state, error_rate, total, rejected, in_flight |
| `BreakerDetail` | GET /api/breakers/{name} | window.buckets, metrics, config, opened_at |
| `GlobalMetrics` | GET /api/metrics | total, succeeded, failed, rejected, error_rate |
| `EventView` | GET /api/events | type, resource, time, data.from, data.to, data.reason |
| `SimulateReq` | POST /api/demo/simulate | resource, fail_rate, latency_ms, seconds |

## 7. 错误与边界处理

- 接口失败：顶部显示轻提示条（不整页报错），保留上次成功数据继续渲染。
- 资源不存在（404）：详情面板显示"资源不存在"，列表自动刷新。
- 浏览器窄屏（<900px）：左右面板改上下堆叠。
- 轮询期间用户正在编辑配置 → 配置表单禁用自动刷新，保存/取消后恢复。
- 数值格式化：错误率百分比保留 1 位小数；大数字千分位分隔。
