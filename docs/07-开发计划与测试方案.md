## 3. 单元测试用例清单

### 3.1 state_test.go（状态机）

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| Closed→Open 阈值触发 | 窗口 10 请求、8 失败、阈值 0.5 | 迁移 Open，openUntil = now + SleepWindow |
| Closed 不触发（请求不足） | 4 请求、4 失败、MinRequests=5 | 保持 Closed |
| Closed 不触发（错误率不足） | 10 请求、4 失败、阈值 0.5 | 保持 Closed |
| Open→Half-Open 冷却到期 | openUntil 已过 | 迁移 Half-Open，探测计数清零 |
| Open 冷却未到期 | openUntil 未到 | 拒绝（RejectedB） |
| Half-Open→Closed 连续成功 | probeSuccess+1 ≥ 阈值 | 迁移 Closed，窗口清空 |
| Half-Open→Open 探测失败 | 任一探测失败 | 迁移 Open，重新计时 |
| 手动 ForceState 各迁移 | 强制切换三种状态 | 目标状态 + 事件发布 |
| String/Color 映射 | 三状态 | 文案与配色正确 |

### 3.2 sliding_window_test.go（滑动窗口）

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| 单桶写入聚合 | 桶内 3 成功 2 失败 | Total=5, ErrorRate=0.4 |
| 桶轮换（时间推进跨桶） | 伪造时间戳跨越 3 桶 | 计数落入正确桶 |
| 过期桶淘汰 | 写入超过窗口时长的桶 | 聚合不含过期桶 |
| 错误率口径 | Failed+Timeout / 总数 | 拒绝类不计入分母 |
| 重置 | Reset 后 | 全部桶清零、StartAt 置空 |
| 并发写入 | 100 goroutine 各写 1000 次 | 无数据竞争（-race），计数精确 |

### 3.3 semaphore_test.go（并发隔离）

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| 基本获取/释放 | 容量 3，获取 3 成功 | 第 4 次 TryAcquire 失败 |
| 不等待超限 | Acquire(0) 满员 | false |
| 等待超时 | Acquire(100ms) 满员 | false（约 100ms 返回） |
| Count/Max | 占用 2 | Count=2, Max=3 |

### 3.4 breaker_test.go（主流程）

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| 正常执行 | fn 返回 (val, nil) | 返回 val，成功计数 +1 |
| 调用失败 | fn 返回 err | 失败计数 +1，返回错误 |
| 熔断拒绝 | 状态 Open | 返回降级结果，RejectedB +1 |
| 并发拒绝 | MaxConcurrency=1 且占满 | 返回 ErrConcurrencyLimit，RejectedC +1 |
| 探测放行 | Half-Open 下连续调用 | 仅 1 个探测执行，其余拒绝 |
| 探测成功恢复 | 探测成功达阈值 | 状态 Closed |
| 超时降级 | fn 阻塞 > CallTimeout | Timeout +1，返回 ErrTimeout |
| panic 恢复 | fn panic | recover，失败计数 +1，不崩溃 |
| FallbackFunc | 熔断时配置兜底函数 | 返回兜底结果 |
| DefaultValue | 熔断时配置默认值 | 返回默认值 |
| 动态配置热更新 | 降低阈值后 | 新阈值立即生效 |
| 事件发布 | 状态迁移/创建/配置变更 | 对应事件被监听器收到 |

### 3.5 registry_test.go（注册中心）

| 用例 | 输入 | 期望 |

## 4. 集成与端到端验证

### 4.1 手动演示步骤（M3 验收）

```
1. go run ./cmd/demo          # 启动 :8080
2. open http://localhost:8080 # Dashboard
3. 演示控制台：payOrder、失败率 80%、时长 15s、注入
4. 观察：列表徽章 绿→红（约 5 秒内，错误率超 50%）
5. 观察：5s 冷却后 红→黄（半开探测）
6. 注入结束后：黄→绿（探测连续成功）
7. 时间线逐条对应上述迁移；柱状图红绿分布正确
8. 手动：切态、重置、改阈值，Dashboard 即时反映
9. 停止注入（Ctrl+C），进程优雅退出
```

### 4.2 自动化冒烟

```bash
go test -race ./... && go vet ./... && test -z "$(gofmt -l .)"
```
